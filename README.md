#Tic-Tac-Toe Game (Java)

##Project Overview
This is a simple two-player Tic-Tac-Toe game developed using Java.

The game is played between two players, X and O, who take turns placing their symbols on a 3x3 grid. The objective is to get three of your symbols in a row, column, or diagonal before the other player.

##Features
Two-player gameplay.
3x3 Tic-Tac-Toe game board.
Players take turns placing X and O.
User input using the Scanner class.
Checks whether a selected position is valid.
Prevents players from placing symbols in occupied spaces.
Keeps track of the number of moves.
Detects horizontal and vertical winning combinations.
Detects when the game ends in a draw.

##Technologies Used
Java – Main programming language.
Scanner – Used to collect player input.
2D Arrays – Used to store and display the game board.
Loops – Used to repeat turns and display the board.
If/Else Statements – Used for checking moves and switching players.

##How to Play
The game starts with Player X.
Players are asked to enter a row number between 1 and 3.
Players then enter a column number between 1 and 3.
Their symbol is placed in the selected position.
Players alternate between X and O.
The game continues until a player wins or the board is full.
